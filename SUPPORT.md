# Support

## Getting help

This is a private research repository, not a product. Support is limited and
best-effort by the sole maintainer.

| I want to… | Do this |
|---|---|
| Run the program | Read `DOCUMENTATION.md` §4–§5, then run `./run-standalone.sh` |
| Understand what this is | Read `README.md`, then `DOCUMENTATION.md` |
| Understand the analysis | Read `analysis/ANALYSIS-DEEP.md` |
| Understand the legal position | Read `LICENSE` and `NOTICE.md` |
| **Contribute** | Read `CONTRIBUTING.md`, then `docs/COMMUNITY.md` |
| Ask a question or share results | Open a [Discussion](https://github.com/NurMohammadDuari/TypingMaster-Source/discussions) |
| Report a bug | Open an issue using the *Bug report* template |
| Correct the analysis | Open an issue using the *Analysis correction* template |
| Report a security problem | **Privately** — see `SECURITY.md` |

## Before opening an issue

1. Run the integrity check and include the result:
   ```sh
   md5sum -c MANIFEST.txt
   ```
2. Confirm you are using the standalone launcher (`./run-standalone.sh`) and
   note your OS.
3. Search existing issues/commits first.

## Not supported

- **Licence bypass.** No keys, cracks or activation help — see `CONTRIBUTING.md`.
- **Upstream bugs.** Problems inside Wine or the Freedesktop runtime belong to
  those projects, not here (`NOTICE.md` lists the upstreams).
- **Piracy / redistribution.** This repository must not be made public or
  redistributed; see `LICENSE`.

## Response expectations

This is a personal project. There is no SLA and no guaranteed response time.
Reports are reviewed on a best-effort basis.
